# Security Policy

## Supported Versions
Security updates are provided for the latest code on `main`.

## Reporting a Vulnerability
If you discover a security issue:

1. Do **not** open a public issue with exploit details.
2. Use GitHub private vulnerability reporting (if enabled), or contact repository maintainers privately.
3. Include:
   - impact summary
   - reproduction steps
   - affected version/commit
   - suggested mitigation (if available)

We will acknowledge and triage as quickly as possible.
